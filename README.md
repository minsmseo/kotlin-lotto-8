# 🎲 로또 (Kotlin) – README

## 1) 목적

간단한 **로또 발매기 프로그램**을 구현한다.  
사용자가 입력한 구입 금액에 따라 로또를 발행하고,  
당첨 번호 및 보너스 번호를 입력받아 당첨 내역과 수익률을 계산하여 출력한다.

---

## 2) 요구사항 요약

* **입력**
  * 구입 금액 (1,000원 단위)
  * 당첨 번호 (쉼표로 구분된 6개)
  * 보너스 번호 (1개)
* **출력**
  * 발행한 로또 목록 (오름차순 정렬)
  * 당첨 내역 (3~6개 일치, 2등은 5개+보너스)
  * 총 수익률 (소수점 둘째 자리 반올림)
* **예외 처리**
  * `[ERROR]`로 시작하는 메시지 출력
  * `IllegalArgumentException` 발생 후 해당 입력부터 재시도
  * `System.exit()`, `exitProcess()` 등 명시적 종료 금지
* **환경**
  * Kotlin 2.2.0  
  * `missionutils.Randoms`, `missionutils.Console` 사용

## 5) 입출력 포맷 + 검증 규칙

### 입력 예시
```
구입금액을 입력해 주세요.
8000
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
보너스 번호를 입력해 주세요.
7
```

### 출력 예시
```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

### 검증 규칙 상세

* **구입 금액**
  * 1,000원 단위가 아니면 `[ERROR]` 예외 발생  
  * 0 이하, 문자 입력 시 예외
* **로또 번호**
  * 1~45 범위, 중복 불가, 6개 입력 필수
* **보너스 번호**
  * 1~45 범위, 당첨 번호 중복 불가
* **출력 형식**
  * 로또 번호는 오름차순 정렬
  * 수익률은 소수점 둘째 자리 반올림
* **종료 방식**
  * 명시적 종료(`System.exit`, `exitProcess`) 금지  
  * 예외 발생 시 해당 입력부터 재시도

---
